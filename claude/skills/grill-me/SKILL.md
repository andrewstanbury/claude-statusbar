name: grill-me
description: Interview the user relentlessly about a plan or design until reaching shared understanding, resolving each branch of the decision tree. Use when user wants to stress-test a plan, get grilled on their design, or mentions "grill me".
---

Interview the user relentlessly about the plan until shared understanding reached. Walk each branch of the decision tree, resolving dependencies one-by-one. For each question, recommend an answer.

Ask one question at a time.

If a question can be answered by exploring the codebase, do that instead.
